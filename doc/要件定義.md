# 🌕 プロジェクト要件定義書: 『LunarEdge』（ルナエッジ）

## 1. プロジェクト概要

- **プロダクト名:** LunarEdge（ルナエッジ）
- **コンセプト:** 割安かつ財務健全でありながら、上昇トレンド（バンドウォーク初期）にある優良銘柄を視覚的に抽出する、個人用の高機能スクリーニングツール。
- **ターゲットユーザー:** 個人利用（自身専用の投資意思決定サポートツール）
- **プラットフォーム:** Webブラウザ（PC・タブレット・スマートフォン対応のレスポンシブSPA）

## 2. システム構成・技術スタック

- **フロントエンド (SPA)**
- フレームワーク: React + TypeScript
- スタイリング: Tailwind CSS
- UIコンポーネント: shadcn/ui
- 状態管理: Jotai
- チャート描画: Lightweight-charts (または Recharts)

- **バックエンド (API)**
- フレームワーク: Python + FastAPI
- データ取得: `yfinance` ライブラリ（※無料・非公式APIのため、リクエスト間隔の制御等に留意）
- データ処理・テクニカル計算: `pandas`, `pandas-ta`

## 3. コアロジック（スクリーニング抽出条件）

対象市場を**東証プライム**とし、以下の全条件を満たす銘柄を抽出する。

- **バリュー（割安性）**
- PBR（実績）: 0.5倍 〜 1.0倍 （※解散価値割れを狙いつつ債務超過を排除）
- PER（会社予想）: 15.0倍以下

- **クオリティ（収益性・効率性）**
- ROE（会社予想）: 8.0% 〜 25.0% （※異常値を排除）
- 売上高営業利益率（会社予想）: 10.0%以上

- **セーフティ（財務健全性）**
- 自己資本比率（実績）: 40.0%以上

- **テクニカル（トレンド）**
- ボリンジャーバンド（期間: 25日, 偏差: 2σ）: 現在値が **+1σ 〜 +2σ** の範囲内に位置すること。
- 除外条件: +3σを超過している銘柄（過熱感）、および極端な出来高過少銘柄。

## 4. 機能要件

1. **スクリーニング実行:** ユーザーの操作（ボタン押下等）をトリガーに、バックエンドAPIへリクエストを送信。
2. **データ処理・計算:** バックエンドにて銘柄データの取得、指標によるフィルタリング、ボリンジャーバンドの計算を実行。
3. **結果一覧表示:** 条件に合致した銘柄群を、グリッドレイアウトのカード形式で一覧表示。
4. **チャートプレビュー:** 各銘柄カード内に、過去半年〜1年分の日足ローソク足チャートを描画。
5. **指標ハイライト:** 各銘柄の主要指標をバッジで表示し、条件に合致している項目を視覚的に強調。

## 5. UI/UX・デザイン仕様

無駄を削ぎ落とし、情報のノイズを減らしたミニマルなUI。長時間の分析に適した「Moon Traders」パレットを基調とする。

### 5.1 カラーパレット（CSS変数マッピング）

- `--background`: `#2f2f6f` (jacarta) - アプリ全体の背景色
- `--card` / `--muted`: `#4f5b7d` (blue bayoux) - カード背景、サブ要素
- `--border` / `--muted-foreground`: `#7890a5` (gothic) - 境界線、グリッド線、補足テキスト
- `--foreground`: `#afc3cf` (casper) - メインテキスト、ローソク足の基本色
- `--primary` / `--accent`: `#f2e5c4` (mint julep) - 強調表示（指標バッジ）、バンドウォーク帯（+1σ〜+2σ）のハイライト

### 5.2 画面レイアウト（Cardコンポーネント構成）

- **レスポンシブ:** PC（3〜4カラム）、タブレット（2カラム）、スマホ（1カラム）
- **CardHeader:** 銘柄コード、企業名（太字）、現在値、前日比（%）
- **CardContent (チャートエリア):** \* 背景に薄い `--border` 色のグリッド線。
- 日足ローソク足。
- ボリンジャーバンドの +1σ 〜 +2σ の間を `--primary` の半透明カラーで塗りつぶし、トレンド帯を可視化。

- **CardFooter (指標エリア):** \* PER, PBR, ROE, 営業利益率, 自己資本比率を shadcnの `<Badge>` コンポーネントで配置。
- スクリーニング条件を牽引している強い指標は `--primary` 背景色で反転強調。
